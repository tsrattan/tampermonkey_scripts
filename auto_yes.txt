✅ Use this (most reliable for your form)
Paste this into the console:
document.querySelectorAll('input[type="radio"][value="Yes"]').forEach(el => {  if (!el.checked) {    el.click();  }});
Why this works well for your form:


Targets only radio buttons with value="Yes"


Avoids re-clicking already selected ones


Matches what your screenshot shows



🚀 Even better (handles weird MS Forms behavior)
Microsoft Forms sometimes hides inputs and uses labels/spans for clicks.
This version is more robust:
document.querySelectorAll('[data-automation-value="Yes"]').forEach(el => {  el.click();});
👉 Based on your screenshot, this is very likely the best one

🧪 If something doesn’t click properly
Use this fallback (label-based):
document.querySelectorAll('span').forEach(el => {  if (el.innerText.trim() === 'Yes') {    el.click();  }});
